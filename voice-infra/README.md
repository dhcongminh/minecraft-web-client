# Webcake voice infrastructure

This stack provides a self-hosted LiveKit server, an authenticated TURN relay, and a token issuer only reachable by the Paper plugin over the Docker `proxy` network.

## Deploy

1. Copy `.env.example` to `.env` and replace every secret.
2. Run `docker compose up -d --build` from this directory.
3. Open these VPS firewall/security-group ports: `3478/tcp`, `3478/udp`, `7881/tcp`, `50000-50100/udp`, and `49160-49200/udp`.
4. Configure the Paper plugin with `issuer-url: http://token-issuer:3000/token` and the same `VOICE_PLUGIN_SECRET` value.

Traefik routes LiveKit signalling at `wss://webcake-team.dhcongminh.id.vn/rtc`; the main web client stays on the same hostname.

TURN credentials are time-limited and generated by the issuer. Do not expose its port or `VOICE_PLUGIN_SECRET` publicly.
